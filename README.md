# Uzay Avcısı

Expo + React Native 2D top-down shooter.

## Yerelde

```bash
npm install
npm run web
```

## Canlı site (GitHub Pages)

Push to `main` → Actions otomatik deploy eder.

Site: https://remedolt.github.io/UFO/

Repo **Settings → Pages → Source: GitHub Actions** olmalı.
